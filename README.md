# 🎯 Objectif du projet

Mesurer l’impact des dépenses publicitaires sur les ventes et prédire les ventes futures à partir des investissements en publicité.

# 🧱 Structure du projet 

## 1️⃣ Introduction & Problématique

### 👉 Pourquoi ce projet existe ?

Les entreprises investissent dans plusieurs canaux publicitaires (TV, Radio, Social Media, etc.).
L’objectif de ce projet est d’analyser l’impact de ces investissements sur les ventes et de construire un modèle prédictif basé sur une régression linéaire.

### Questions clés :

- Quels canaux publicitaires influencent le plus les ventes ?
- Existe-t-il une relation linéaire entre publicité et ventes ?
- Peut-on prédire les ventes à partir des budgets publicitaires ?
